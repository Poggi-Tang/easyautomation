# 模型、离线与密钥配置

[English](model-and-privacy.md) | 简体中文

## 三种运行方式

- **仅本地功能**：不填写 API 配置。可管理知识库、手动添加控件、使用本地 YOLO / RapidOCR 进行基本扫描，以及编排和运行已有组合动作。
- **本地功能加云端多模态模型**：通过 OpenAI 兼容 API 配置支持图片输入与 JSON 输出的多模态模型，用于语义说明、参考资料整理和深度学习。所用服务的费用和可用性由服务商决定。
- **本地功能加内网多模态模型**：配置本机或内网的兼容多模态模型服务；模型能力要求相同。离线包不提供该服务，需要自行部署。

首次从源码运行 `setup.bat` 需要下载依赖和模型。发布页的完整 GUI ZIP 和完整离线部署 ZIP
已包含运行环境、检测权重及 OCR 模型；本地功能可以在解压安装后离线使用。
这不代表目标软件、远程网页资料或云端模型也能离线使用。

## 学习过程使用哪些数据

| 操作 | 本地处理 | 配置的模型端点收到的内容 |
| --- | --- | --- |
| GUI 基本学习，不补充控件含义 | 截图、YOLO、OCR、UIA 匹配、写入知识库 | 无 |
| 补充控件含义 | 本地扫描和匹配 | 窗口截图、控件属性、区域信息；资料辅助说明还包含相关参考片段 |
| 导入参考资料 | 读取文件、提取文字、缓存进度 | 分段的资料文字、来源信息和相关软件信息，用于整理索引和核对引用 |
| 深度学习 | 操作目标软件、捕获结果、保存区域/控件/流程 | 当前截图、探索进度、用户要求、相关参考内容与测试输入 |
| CLI / MCP 视觉优先扫描 | UIA 匹配、定位验证、保存知识 | 所选窗口或分块截图 |
| 操作响应解释 | 记录前后状态、计算变化 | 目标窗口前后截图、相关弹窗裁剪图及控件变化 |
| 显式开启的远程视觉定位 | 校验返回位置 | 所请求范围的截图与目标描述 |
| 获取模型列表 | 填充模型选择框 | 认证请求；不发送截图或参考资料 |

GUI 的“导入参考资料”目前同时执行提取和模型整理；只安装 OCR 不能完成该流程。
“基本学习”不会点击目标软件，但启用含义补充后仍会调用 API。
本地 YOLO 是检测模型，RapidOCR 是文字识别工具；二者不会自主理解业务或规划交互。

知识库中的 Markdown、图片和参考原文是普通本地文件，不自动加密。版本管理需要自行配置 Git；
当前没有内置的团队权限管理、流程版本回滚或多机器调度服务。

## API Key 保存与升级

从 1.1.0 起，Qt GUI 和独立配置 EXE 中的 API Key 默认隐藏，点击“显示”可临时查看。
保存或 CLI 配置时，Key 写入当前 Windows 用户的凭据管理器，目标名称为
`easy-uiauto/vision-api-key`。路径、API URL 和模型名称继续保存在用户环境变量中。
凭据保护的是本机保存，不替代模型服务的访问控制。

读取顺序为：Windows 凭据管理器 → 用户环境变量 → 当前进程环境变量 → 原有
`mcp_servers.easy_uiauto.env` 配置。只读取本应用的设置，不读取其他应用的凭据。
已保存的凭据优先，修改旧环境变量不会覆盖它；换 Key 时应在设置中保存。

旧配置可直接读取，无需立即重新输入 Key。成功保存后会清除旧的
`EASY_UIAUTO_VISION_API_KEY` 用户环境变量和当前进程中的副本；保存失败则恢复原有设置，
不会退回明文存储。普通 GUI 保存不会改写已有的客户端配置文件，历史文件中的明文副本也不会自动清除。
重新注册 Codex MCP 时会迁移本应用的设置并替换其旧条目。

GUI、MCP 和 Python 应一起升级到 1.1.0，再保存配置；旧版本不支持从凭据管理器读取。
同一用户运行的新 GUI 和 MCP 会动态读取新值，跨用户或另一台机器需要单独配置 Key。
运行中的旧客户端可能仍持有继承的环境变量，升级后重启即可。

Key 不写入知识库或安装包。模型请求错误只报告状态码或固定说明，不展示服务商返回的错误正文，
避免无效 Key 被服务商回显后进入日志。自定义代理、第三方 SDK 或用户脚本自行记录的请求不受此设置控制。

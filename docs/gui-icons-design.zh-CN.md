# GUI 图标设计清单

本方案对应当前 PySide6 知识库管理界面，覆盖知识树、顶部操作、上下文操作栏、步骤编辑、模型设置和运行状态。已按下列规格绘制并接入 50 个 SVG，覆盖 49 个语义图标，其中开关分别为 `toggle-on.svg`、`toggle-off.svg`。关闭、取消等次要按钮按布局约束保留文字。

图标源文件位于 `src/easy_uiauto/resources/icons/`，可查看[交互预览](gui-icons-preview.html)和[整套预览图](assets/gui-icons/contact-sheet.png)。预览支持按名称筛选、切换尺寸及禁用/选中外观，也可单独下载 SVG。

## 统一规范

- **风格**：圆角线性图标，平面、透明底，不使用渐变、立体效果或装饰阴影。与现有 Logo 的蓝色方向呼应；应用 Logo 作为品牌标识单独保留。
- **尺寸**：统一 24 × 24 设计网格，四周至少 2 单位留白，主线宽 1.75，圆头、圆角；导航树/菜单显示 16 px，普通按钮显示 18 px，主要入口显示 20 px。16 px 版本允许简化内部线条。
- **复杂度**：一个主体，至多一个辅助符号；辅助符号固定在右下角。禁用微小文字，例外是通用符号本身；录制圆点和停止方块采用实心以保持辨识度。
- **交互**：按钮保留文字，图标在文字左侧，间距 6–8 px；知识树图标在名称左侧。状态图标与状态文字配对，不能只靠颜色区分。
- **配色**：默认每个图标使用一种语义色；同一资产在不同位置保持含义。普通操作优先蓝灰色，成功、警告、失败使用对应状态色。
- **状态**：悬停仅调整按钮底色，图标不跳色、不放大；禁用统一灰色；在深色选中背景上使用白色版本，继续保留文字含义。深色主题另映射颜色，不直接套用浅色主题色值。
- **交付**：SVG 为源文件，路径绘制、不依赖字体或外链。需要 PNG 时再导出 16/20/24/32/48 px；常规、禁用、选中颜色通过主题映射获得，不重复设计形状。

| 色名 | 色值 | 使用原则 |
|---|---|---|
| 功能蓝 | `#2563EB` | 导航、创建、选择、文件操作、定位 |
| 中性灰 | `#475569` | 设置、编辑、查看、排序、一般工具 |
| 智能紫 | `#7C3AED` | 本地模型与自动学习 |
| 成功绿 | `#15803D` | 运行入口、已就绪、已通过 |
| 提醒橙 | `#B45309` | 待确认、缺失、隔离、需要处理 |
| 危险红 | `#DC2626` | 删除、停止、录制、失败；必须由造型和文字进一步区分 |
| 禁用灰 | `#9CA3AF` | 当前不能操作的控件，不用于表示失败 |
| 选中白 | `#FFFFFF` | 深色选中背景上的图标 |

## 复用及布局约束

1. 共 **49 个语义图标**；toggle 有启用/停用两个几何状态。颜色变体和尺寸变体不算新图标。
2. 知识树的“对象类型”放在名称列，状态图标放在状态列，不将警告、勾选、连接等小徽章全部叠到对象图标上。
3. “添加软件、添加区域、添加状态、新建流程”分别复用 window、region、layers、workflow，不另画四个“主体 + 加号”。通用新增用 add。
4. “选择文件、浏览、切换知识库”共用 folder-open；“运行、执行”共用 play；“刷新、重查、重整”共用 refresh。
5. 模型对话框顶部使用 model-chip，三行继续以“图形检测、文字定位、文字识别”文字区分；每行只补状态图标，不新增三套装饰性模型图标。
6. 步骤类型仍保留“点击、双击、右击、输入”等文字，首轮不为每种鼠标动作画一个近似图标。Ctrl、Alt 等键名不画进图标。
7. 关闭、取消、返回等次要按钮允许保留纯文字；准备通用图标不表示所有按钮都必须显示图标。普通属性字段标签保持文字。
8. 主界面按钮使用图标加文字，最多一个图标；不因增加图标扩大工具栏高度。空页面不增加大型装饰插画。
9. 启用/停用图标表达当前参考资料状态，按钮文字表达下一步动作；模型下载切换为停止时，文字与 download/stop 图标同步切换。

## 制作顺序

- **第一批 28 个**：01–15、17–18、21、23–24、33–36、44–46、48。覆盖导航、顶部入口、常用操作、学习定位和关键状态，视觉改善最明显。
- **第二批 21 个**：16、19–20、22、25–32、37–43、47、49。补齐低频菜单、步骤编辑和辅助状态。

后续验收时检查：16 px 下是否仍能辨认；同类图标视觉大小是否一致；红色录制圆、停止方块、删除桶是否分明；图标与实际按钮含义是否匹配；选中、禁用和高 DPI 下是否清晰。

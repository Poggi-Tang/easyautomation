easy-uiauto 采用个人免费、企业付费授权的方式，GUI、MCP、Python API、
命令行与随附 Skill 使用同一套授权规则。定制开发、代配置和使用方案另行报价。

## 使用范围

| 场景 | 授权方式 |
| --- | --- |
| 个人学习、研究、日常使用 | 免费 |
| 独立开发者为自己开发项目，包括产生收入的项目 | 免费；不包括出售本软件或向企业提供托管自动化服务 |
| 员工为所在企业配置、测试、运行自动化 | 企业付费授权 |
| 顾问或外包人员受企业委托执行项目 | 按企业实际使用主体和服务范围取得商业授权 |
| 企业试用、评估 | 联系约定书面评估授权与期限 |
| 其他组织使用 | 联系约定授权和费用 |

以实际使用目的判断授权，使用个人电脑或个人账号不会把企业业务变成个人用途。
企业内部自用同样属于企业使用，不以是否对外销售作为判断标准。
源码可见不代表可以不受限制地商用；具体权利以 LICENSE 或双方书面协议为准。
